# ElvUI Additional Feature

## English
An enhancement plugin for ElvUI that adds several highly requested quality-of-life features and customizations.

### 🌟 Features

* **Force Solo Threat Color**
  Forces the Nameplate "Solo Threat Color" to apply even when you are in a party or raid group.
* **Nameplate Interrupt Color**
  Visually confirm successful interrupts! Changes the target's castbar to a custom color instantly upon a successful interrupt.
* **Custom Reaction Color Tag**
  Replaces ElvUI's default reaction colors with your own! Creates a fully customizable text tag (e.g., `[eAF_reactioncolor]`) that you can apply to any UnitFrame or Nameplate. Friendly, Neutral, and Hostile colors are all fully adjustable.
* **Disable Aura Sweep Animation**
  Hides the dark "sweep" (radial cooldown animation) on your player Buffs and Debuffs, leaving only the clean cooldown text.

### 🛠️ Installation

1. Download the latest version.
2. Extract the `ElvUI_AdditionalFeature` folder.
3. Move the folder into your `World of Warcraft\_retail_\Interface\AddOns\` directory.
4. Make sure ElvUI is installed and enabled.

*For detailed version history and updates, please see the [CHANGELOG.md](CHANGELOG.md).*

## 简体中文
一个 ElvUI 的增强插件，添加了多个高度需求的生活质量改善和自定义功能。

### 🌟 功能特性

* **强制单人仇恨颜色**
  强制姓名板使用“单人仇恨颜色”，即使你当前处于小队或团队中也会生效。
* **姓名板打断变色**
  视觉化确认打断成功！当成功打断目标施法时，施法条会瞬间变为你自定义的颜色。
* **自定义声望颜色标签**
  用你自己的颜色替换 ElvUI 默认的声望颜色！创建一个完全可自定义的文本标签（例如 `[eAF_reactioncolor]`），你可以将其应用于任何单位框架或姓名板中。友善、中立和敌对颜色均可自由调节。
* **关闭光环冷却动画**
  隐藏玩家 Buff 和 Debuff 上的深色“阴影”（转圈冷却动画），只保留干净的冷却倒计时数字。

### 🛠️ 安装方法

1. 下载最新版本。
2. 解压 `ElvUI_AdditionalFeature` 文件夹。
3. 将文件夹移动到你的 `World of Warcraft\_retail_\Interface\AddOns\` 目录中。
4. 确保你已安装并启用了 ElvUI 核心插件。

*有关详细的版本历史和更新记录，请查看 [CHANGELOG.md](CHANGELOG.md)。*
